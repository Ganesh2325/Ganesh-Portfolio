> *Oct 2026*

An AI agent governance, safety & observability platform with human-in-the-loop approval and end-to-end traceability.

## 📁 Portfolio — Tech Stack

This portfolio website is built with:

| Technology | Purpose |
|---|---|
| **Next.js 16** | App Router, SSR, static generation |
| **React 19** | UI components |
| **TypeScript** | Type-safe development |
| **Tailwind CSS v4** | Utility-first styling |
| **GSAP** | Animations & scroll effects |
| **Lenis** | Smooth scroll |
| **Vercel** | Deployment & hosting |

### Run Locally

```bash
# Clone the repository
git clone https://github.com/Ganesh2325/Ganesh-Portfolio.git
cd Ganesh-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```
